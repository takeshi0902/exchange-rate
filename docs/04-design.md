## 視覺設計系統（v1，2026-10-18）

### 設計依據

- 題材：台灣人出國前的金融決策（換匯、刷卡、退稅）
- 讀者：準備出國的台灣旅客，以手機瀏覽為主 `[假設]`
- 主要任務：讓人在出發前快速知道「去哪換、換多少、省多少」，並信任資料
- 方向：**登機證**（使用者於 `docs/design/directions.html` 三選一選定 C）

### 原則

1. **大膽只用在一個地方**：登機證只出現在首頁主視覺（`.pass`），其他頁保持安靜、清楚。
2. **數字是主角**：匯率、金額一律用 Barlow Condensed ＋ 等寬數字，對齊好比較。
3. **結構即資訊**：虛線撕線只用來分隔「主要資訊」與「結論」（票根）；不加裝飾性標籤、編號、emoji 標題。
4. **文字說人話**：按鈕說清楚會發生什麼（「比較 6 家銀行」，而不是「查看更多」）。

### 色彩 token（`site/css/style.css` 的 `:root`）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#eef3f9` | 頁面底色（淡天空藍） |
| `--card` | `#ffffff` | 票面、卡片、表格底 |
| `--text` | `#10233d` | 深藍墨，主要文字 |
| `--text-muted` | `#4d5d72` | 次要文字、欄位名稱 |
| `--primary` | `#0057b8` | 航線藍：按鈕、連結、目前頁面 |
| `--success` | `#0a7a4f` | 最划算 |
| `--accent` | `#e2412e` | 票根紅：只用於「省多少」這類結論數字 |
| `--border` | `#c9d6e6` | 邊框、虛線撕線 |

### 字體

- 中文與內文：Noto Sans TC（400 / 500 / 700 / 900）
- 數字、貨幣代碼：Barlow Condensed（500 / 700），`font-variant-numeric: tabular-nums`
- 由 `style.css` 頂端統一載入，頁面不需各自引用

### 圓角層級

| Token | 值 | 用途 |
|---|---|---|
| `--radius-lg` | 16px | 登機證 |
| `--radius` | 10px | 卡片、輸入框、按鈕 |
| `--radius-sm` | 6px | 標籤、提示 |
| 膠囊 | 999px | 幣別切換 tab |

### 自我檢查（對照 AI 生成網站常見套版）

- 未使用米色底＋宋體、黑底＋螢光色、報紙式細線版面
- 卡片不用統一灰陰影，改用邊框；只有登機證有陰影，強調它是「實體票」
- 標題不加 emoji、不用全大寫標籤、不在標題中單獨變色強調某個詞
- 按鈕與連結文字不加「→」

### 品質底線

- 手機優先，最小寬度 320px 不出現橫向捲動
- 鍵盤操作有明顯 focus 外框
- 支援 `prefers-reduced-motion`
- 文字對比度符合 WCAG AA
