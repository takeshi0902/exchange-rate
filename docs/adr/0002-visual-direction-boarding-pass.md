# ADR 0002：視覺方向採「登機證」，設計系統集中於 style.css

- 日期：2026-10-18
- 狀態：已採用

## 背景

原網站為通用的藍色 Google 風格，無辨識度。收入依賴流量與社群分享，需要一眼可辨的視覺。使用者要求大改，且易維護。

## 決定

- 視覺方向：登機證（TWD ✈ JPY 為航線，最佳銀行與可換金額為票面資訊）
- 所有顏色、字體、圓角以 CSS 變數定義於 `site/css/style.css` 的 `:root`；保留原有變數名稱（`--primary`、`--success` 等）以免頁面樣式失效
- 頁面內不得寫死顏色值；JS 繪圖（Chart.js）由 CSS 變數讀取顏色

## 考慮過的選項

| 選項 | 優點 | 缺點 |
|---|---|---|
| A 機場翻牌看板 | 數字最好讀 | 文章頁單調 |
| B 護照內頁 | 可信度高，適合文章 | 宋體在手機偏正式；工具頁較弱 |
| **C 登機證** | 記憶點最強，一張票回答「去哪換、換多少、省多少」 | 母題只能用一次，其他頁靠設計系統支撐 |

## 後果

- 改色或換字體只需改 `:root`
- 新頁面只要使用既有 class（`.card`、`.btn`、`.tabs`、`.table-wrap` 等）即自動套用風格
